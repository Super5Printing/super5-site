# superfiveprinting.com

Site estático da Super 5 Printing. Vitrine — todos os CTAs levam para o WhatsApp.

## Estrutura

    index.html    página única, uma seção por bloco
    img/          imagens otimizadas (WebP) usadas pelo site

## Publicação

Conectado ao Cloudflare (Workers com static assets ou Pages).
Cada push na branch `main` publica automaticamente.

Configuração no painel da Cloudflare:

- Build command: deixar vazio (não há build)
- Build output directory: `/`
- Branch de produção: `main`

## Domínio

`superfiveprinting.com`, registrado na GoDaddy. O DNS aponta para a Cloudflare.
